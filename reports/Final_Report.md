# Bluestock Mutual Fund Analytics Capstone

## Executive Summary

This project builds a complete analytics platform for mutual fund analysis. The solution covers ETL pipelines, database design, exploratory analysis, performance measurement, risk analytics, investor behavior analysis, and dashboard reporting.

## Data Sources

* Fund Master
* NAV History
* Investor Transactions
* AUM Data
* SIP Data
* Category Inflows
* Benchmark Indices
* Portfolio Holdings

## ETL Design

* Raw data ingestion
* Validation
* Cleaning
* SQLite storage
* Analytics layer

## Exploratory Data Analysis

### Key Findings

1. Industry AUM increased significantly from 2022–2025.
2. SBI Mutual Fund maintained the highest AUM.
3. SIP inflows reached ₹31,002 Cr in Dec 2025.
4. Retail participation increased substantially.
5. Small-cap and flexi-cap funds attracted strong inflows.

## Performance Analytics

* CAGR Analysis

* Tracking Error

## Advanced Analytics

* VaR & CVaR

## Limitations

* Limited historical NAV period
* Dashboard developed on macOS using Streamlit
* No Power BI Desktop availability

## Recommendations

* Add real-time market feeds
* Deploy cloud dashboard

## Conclusion

The project successfully demonstrates an end-to-end mutual fund analytics platform covering data engineering, analytics, risk measurement, and business intelligence.
