# Bluestock Mutual Fund Analytics Capstone

## Project Overview

This project analyzes mutual fund industry data using Python, SQL, and analytics techniques. The objective is to build an end-to-end analytics pipeline covering data ingestion, cleaning, exploratory analysis, fund performance evaluation, risk analytics, and dashboard visualization.

## Objectives

* Data ingestion and validation
* Data cleaning and preprocessing
* SQL database design
* Exploratory Data Analysis (EDA)
* Fund performance analytics
* Risk analytics and investor analytics
* Interactive dashboard development
* Final reporting and presentation

## Technology Stack

* Python
* Pandas
* NumPy
* SQLite
* SQLAlchemy
* Matplotlib
* Seaborn
* Plotly
* Streamlit
* Jupyter Notebook

## Project Structure

* data/raw → Raw datasets
* data/processed → Cleaned datasets
* notebooks → Analysis notebooks
* reports → Charts, reports, exports
* scripts → ETL and utility scripts
* sql → Schema and SQL queries
* dashboard → Streamlit dashboard

## How to Run

### Install Dependencies

pip install -r requirements.txt

### Run Data Ingestion

python scripts/data_ingestion.py

### Run Dashboard

streamlit run dashboard/app.py
